## M2 — 전투 코어

> 성격이 M1과 다르다. 화면보다 **순수 로직**이 중심이고, 검증은 스크린샷이 아니라 테스트와 시뮬레이터가 한다.
> 데미지 공식은 ADR-009로 확정됐다. 모든 상수는 `src/data`로 뺀다 — 하드코딩 금지 (CLAUDE.md 규칙 6).

- [x] **T-013** 전투 상태 머신 골격 — `core/battle`, 턴 큐(AGI + 시드 흔들림), 이벤트 로그, 승패 판정. 결정론 검증 포함
- [x] **T-014** 스탯 계산과 데미지 해석 — ADR-009 공식, 속성 내성, 치명타, `applyDamage`/`applyHeal`. 관통 하한이 무적을 막는지 검증
- [x] **T-015** 기본 커맨드 — 공격 / 방어 / 도망. 대상 검증, 방어 배율, AGI 기반 도망 성공률, `fled` 결과 추가
- [x] **T-016** 스킬과 자원 — MP 소비, 침식 누적, 임계 도달 시 폭주·봉인. 자원 부족 시 커맨드 거부
  - **범위 조정**: 아이템은 T-016b 로 분리했다. 인벤토리(수량 관리)가 전투 상태에 들어와야 해서 한 이터레이션에 넣기엔 컸다
- [x] **T-016b** 아이템 커맨드 — 인벤토리 수량 소비, 회복·해독·정화석·부활. 사용 불가 사유를 문자열로 반환
- [x] **T-017** 상태이상 5종 — 지속 턴, 해제 조건, 중복 시 갱신 규칙, 적용 우선순위 (GDD §6.2에 명문화)
- [x] **T-018** 적 AI — 가중치 행동 선택, HP 임계 페이즈 전환, 대상 선택 3종, 사용 불가 선택지 자동 배제
- [x] **T-019** 밸런스 시뮬레이터 + 불변식 테스트 — `tools/sim.ts`, `tests/balance/`. 측정 가능한 불변식 4개 통과
  - **불변식 3개(지배 전략·조합 다양성·사장된 유물)는 유물이 없어 측정 불가.** `it.todo` 로 남겨뒀고 M3에서 실제 테스트로 바꾼다
- [x] **밸런스: 레벨 간 난이도 붕괴 수정** — 침식 임계를 최대 MP에 비례시키고(선택 a), 실측으로 드러난 진짜 원인(보스 MP 풀과 고위력 스킬 비용)까지 함께 고쳤다. 보스전 승률 99/44/39 → 100/98/63 (ADR-010)
- [x] **T-020** 전투 씬 UI — 프론트뷰, HP·MP·침식 바, 커맨드/스킬/아이템 메뉴, 대상 커서, 이벤트 로그 재생. 스모크가 전투 1회를 끝까지 진행
- [x] **T-021** 인카운터 연결 — 걸음 수 카운터, 지역별 테이블, 탐색 ↔ 전투 전환과 복귀, 파티 상태 유지. **M2 완료**
