## M4 — 거점과 저장

> GDD §6.4·§6.5 를 근거로 M3 완료 시점에 생성했다.
> **세이브가 이 마일스톤의 축이다.** 유물 숙련도·침식은 전투 밖으로 이어지는 값이라
> 스키마를 바꾸면 마이그레이션이 필요하다 (CLAUDE.md 규칙 7 — 여기서 처음 실제 의미를 갖는다).

- [ ] **T-037** 세이브 스키마와 마이그레이션 골격
  - DoD: `core/save` — 버전 필드, 마이그레이션 체인, 알 수 없는 버전 거부. localStorage 는 게임 레이어가 맡는다 (ADR-001)
  - 저장 대상: 파티 활력·침식·상태이상, 유물 소지·장착·숙련도, 인벤토리, 현재 맵과 위치
  - **먼저 만든다.** 저장할 것이 늘어난 뒤에 스키마를 얹으면 마이그레이션 첫 판부터 필요해진다
- [ ] **T-038** 슬롯 3개 저장/불러오기 UI
  - DoD: 타이틀에서 이어하기, 거점에서 저장. 슬롯마다 요약(진행 위치·플레이 시간·파티 레벨)
- [ ] **T-039** 유물 회수 지점
