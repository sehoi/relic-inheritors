# 아키텍처 결정 기록 (ADR)

되돌리기 비싼 판단만 기록한다. 사소한 구현 선택은 여기 쓰지 않는다.
루프가 **경계를 바꿔야 한다고 판단하면, 바꾸지 말고 여기에 문제를 적고 멈춘다.**

형식:

```md
## ADR-00N · <제목>
- 날짜 / 상태: 채택 | 대체됨 | 보류(사용자 판단 필요)
- 맥락:
- 결정:
- 결과 및 트레이드오프:
```

---

## ADR-001 · core 레이어에 Phaser 의존성을 금지한다
- 2026-08-04 / 채택
- 맥락: 자율 루프는 자동 검증 신호가 없으면 동작할 수 없다. 게임 로직이 엔진에 결합되면 헤드리스 테스트가 불가능해진다.
- 결정: `src/core/**`는 순수 TypeScript로 유지하고 `phaser` import를 ESLint로 금지한다. 렌더링은 `src/game/**`에서만.
- 결과: 코드가 한 겹 늘어나고 어댑터가 필요하다. 대신 전투·성장·세이브 로직 전체가 1초 내 테스트 가능해진다. 자율 개발의 전제 조건이므로 비용을 감수한다.

## ADR-002 · 모든 무작위성은 시드 RNG를 경유한다
- 2026-08-04 / 채택
- 맥락: 재현 불가능한 버그는 자율 루프가 수정할 수 없다. 밸런스 검증도 결정론 없이는 성립하지 않는다.
- 결정: `Math.random()` 직접 호출 금지. `core/rng`의 시드 기반 RNG만 사용하고, 전투 로그에 시드를 남긴다.
- 결과: RNG 상태를 명시적으로 넘겨야 해서 함수 시그니처가 길어진다. 대신 버그가 회귀 테스트로 즉시 전환되고, 헤드리스 밸런스 시뮬레이션이 가능해진다.

## ADR-003 · 백로그를 GitHub Issues가 아닌 저장소 파일로 둔다
- 2026-08-04 / 채택
- 맥락: 루프가 매 이터레이션마다 작업 큐를 읽는다.
- 결정: `docs/BACKLOG.md` 파일을 단일 출처로 사용한다.
- 결과: API 왕복이 없고 진행이 git diff로 남는다. 대신 여러 에이전트가 병렬로 일할 때 충돌한다 — 현재는 직렬 진행이므로 문제없다. 병렬화가 필요해지면 재검토한다.
