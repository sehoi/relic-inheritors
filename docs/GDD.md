# 게임 기획서 (GDD)

> 이 문서는 **백로그 생성의 근거**다. 루프는 백로그가 바닥나면 여기를 읽고 다음 태스크를 만든다.
> 따라서 여기 적히지 않은 것은 만들어지지 않는다. 방향을 바꾸고 싶으면 코드가 아니라 이 파일을 고친다.

## 1. 한 줄 요약

*(가제)* — 왕국이 무너진 뒤, 잊힌 유적을 따라가며 세계가 왜 이렇게 되었는지를 밝히는
**고전 정통 판타지 턴제 JRPG**. 드퀘/파판 1~6 계열의 문법.

## 2. 설계 축

| 축 | 결정 |
|---|---|
| 시점 | 탑다운 2D, 타일 기반 |
| 전투 | 턴제 커맨드, 프론트뷰(적만 표시) → 추후 사이드뷰 검토 |
| 파티 | 최대 4인 |
| 진행 | 월드맵 → 마을 → 던전 → 보스, 선형에 가까운 구조 |
| 목표 플레이타임 | 수직 슬라이스 30분 → 최종 4~6시간 |
| 난이도 | 중간. 랜덤 인카운터로 성장을 강제하되, 갈아넣기 부담은 낮게 |

## 3. 핵심 루프

```
탐색 → 인카운터 → 전투 → 보상(EXP·골드·아이템) → 성장 → 더 깊은 곳 탐색
        └──────── 마을에서 회복·장비 구매·정보 획득 ────────┘
```

## 4. 시스템 명세 (구현 대상)

### 4.1 이동 / 탐색
- 4방향 그리드 이동, 타일 충돌
- 카메라 추적, 맵 전환(입구/계단/포탈)
- NPC 상호작용, 대화창(텍스트 페이지네이션, 분기 선택지)
- 보물상자, 잠긴 문(플래그·키 아이템)
- 랜덤 인카운터: 걸음 수 카운터 + 지역별 인카운터 테이블

### 4.2 전투
- 턴 순서: 민첩(AGI) 기반 정렬 + 소량의 난수 흔들림
- 커맨드: 공격 / 스킬 / 아이템 / 방어 / 도망
- 데미지 공식(초기안, `data`에 파라미터화):
  `damage = max(1, (ATK * skillPower / 100) - DEF/2) * variance(0.9~1.1) * elementMod * critMod`
- 속성: 화 / 수 / 뇌 / 지 / 무속성 → 상성표는 데이터
- 상태이상: 독, 마비, 수면, 침묵, 혼란 (턴 카운트 감소, 해제 조건)
- MP 자원, 스킬 습득은 레벨업 테이블 기반
- 적 AI: 가중치 기반 행동 선택 (HP 임계값에 따른 페이즈 전환 지원)
- 보스: 고유 AI + 페이즈

### 4.3 성장
- 레벨 1~50, EXP 곡선은 데이터 (`nextExp(level)`)
- 스탯: HP, MP, ATK, DEF, MAG, RES, AGI, LUK
- 장비 슬롯: 무기 / 방어구 / 방패 / 장신구
- 아이템: 소모품(회복·부활·상태해제), 장비, 키 아이템

### 4.4 UI
- 타이틀 / 세이브 슬롯 3개 / 메인 메뉴(아이템·스킬·장비·스테이터스·설정·저장)
- 전투 UI: HP·MP 바, 커맨드 창, 대상 선택 커서, 데미지 팝업, 메시지 로그
- 상점 UI(구매/판매), 여관, 회복 지점

### 4.5 저장
- 슬롯 3개, localStorage
- 스키마 버전 + 마이그레이션 체인

## 5. 콘텐츠 계획 (수직 슬라이스 = M5)

| 항목 | 수량 |
|---|---|
| 파티원 | 2명 (전사, 마법사) — 이후 4명까지 |
| 마을 | 1 (여관·상점·NPC 5명) |
| 던전 | 1 (3층, 보물 4개, 잠긴 문 1개) |
| 잡몹 | 6종 |
| 보스 | 1 (2페이즈) |
| 스킬 | 12 |
| 아이템 | 20 |

## 6. 마일스톤

| ID | 마일스톤 | 완료 조건 |
|---|---|---|
| **M0** | 부트스트랩 | `npm run dev`로 빈 씬이 뜨고, CI 초록, `npm run verify` 통과 |
| **M1** | 탐색 | 타일맵 위를 걷고, 충돌하고, NPC와 대화하고, 맵을 이동할 수 있다 |
| **M2** | 전투 코어 | 인카운터 → 턴제 전투 → 승리/패배가 완결된다. 시뮬레이터로 1000회 자동 전투가 돈다 |
| **M3** | 성장·장비 | 레벨업, 인벤토리, 장비 착용, 상점 구매/판매 |
| **M4** | 저장·메뉴 | 3슬롯 저장/불러오기, 전체 메뉴 UI |
| **M5** | 수직 슬라이스 | 마을1 + 던전1 + 보스1을 처음부터 끝까지 30분 플레이 가능 |
| **M6** | 폴리시 | BGM/SFX, 화면 전환 연출, 타이틀·엔딩, 밸런스 패스 |

## 7. 아직 정하지 않은 것 (루프가 임의로 정하지 말 것)

- 세계관 고유명사(국가명, 주인공 이름) → 사용자 확정 전까지 `TODO_NAME` 플레이스홀더 사용
- 아트 방향 (도트 해상도, 컬러 팔레트) → M1까지는 무료 CC0 에셋 또는 단색 플레이스홀더
- 사이드뷰 전투 전환 여부 → M2 완료 후 재검토
