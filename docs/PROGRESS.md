# 진행 저널

위에서부터 읽으면 최근 진행 상황이 파악된다.

형식:

```md
### YYYY-MM-DD · T-0NN · <제목>
- 한 일:
- 알게 된 것:
- 다음에 걸릴 것 같은 것:
```
